# Photo Album

Java Swing을 활용하여 구현한 데스크톱 사진 앨범 애플리케이션입니다.
Java객체지향 프로그래밍 과제용 - 근데 객체지향을 하지 않는 개망한 앨범프로그램

## 주요 기능

### 1. 로그인
- 사용자 아이디 및 비밀번호 입력
- 로그인 성공 여부 확인
- 입력값 초기화 기능

### 2. 사진 관리
- 로컬 파일을 선택하여 앨범에 사진 추가
- 이전 사진 및 다음 사진 탐색
- 선택한 사진 삭제
- 이미지 크기에 맞춰 화면에 사진 표시

### 3. 사진별 메모 관리
- 현재 사진에 대한 메모 작성
- 메모 저장 및 불러오기
- 메모 삭제 및 입력 내용 초기화
- 사진별 텍스트 파일을 이용한 메모 관리

### 4. 비밀번호 변경
- 현재 비밀번호 확인
- 새로운 비밀번호 저장
- 파일 기반 비밀번호 정보 관리

### 5. 사용자 인터페이스
- Java Swing 기반 GUI
- 기능별 버튼 및 별도 설정 창 구성
- 버튼 조작에 따른 효과음 재생
- 사용 방법 안내 창 제공

## 기술 스택

- **Language:** Java
- **GUI:** Java Swing, AWT
- **File I/O:** Java I/O, NIO
- **Image Processing:** Java ImageIO
- **Audio:** Java Sound API
- **Development Environment:** IntelliJ IDEA 프로젝트 설정 포함

## 프로젝트 구조

```text
photoalbum/
├── src/
│   ├── Main.java           # 메인 화면 및 사진·메모 관리
│   ├── loginView.java      # 로그인 화면 및 인증 처리
│   └── setting_Window.java # 비밀번호 변경 화면
├── res/
│   ├── icon/               # UI 아이콘 리소스
│   └── sound/              # 효과음 리소스
├── Passwd/                 # 비밀번호 관련 파일
├── Text/                   # 사진 경로 등 텍스트 데이터
└── README.md
```

## 실행 환경

- Java JDK
- Java Swing 및 AWT를 지원하는 데스크톱 환경
- 프로젝트에 포함된 이미지 및 사운드 리소스


> 실행 시 필요한 사진 디렉터리와 데이터 파일이 준비되어 있어야 합니다. 현재 코드에는 실행 경로에 의존하는 부분이 있으므로, 다른 환경에서 실행하려면 경로 설정을 확인해야 합니다.

## 구현을 통해 학습한 내용

- Java Swing을 이용한 데스크톱 GUI 구성
- 이벤트 리스너를 활용한 사용자 입력 처리
- 파일 입출력을 통한 데이터 저장 및 불러오기
- ImageIO를 이용한 이미지 로딩과 화면 출력
- 클래스별 화면 기능 분리 및 객체 간 연동
- 로컬 파일을 활용한 로그인 정보 및 메모 관리
